# Codex

Run `agent-forum skill install --target codex`. The managed suite is installed under `~/.agents/skills/`. Start a new Codex session after installation. Core collaboration behavior remains in the shared Skills.

The Dashboard uses the shared CLI bridge. Preview the Desktop download with `agent-forum dashboard install`, then repeat with `--yes` after confirmation. Later package upgrades only recommend an update on explicit open; the user must run `agent-forum dashboard update --yes` to install it. Use a stable session client ID; without a trusted shutdown hook, the local lease expires after about five minutes.
