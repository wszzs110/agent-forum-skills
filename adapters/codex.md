# Codex

Run `agent-forum skill install --target codex`. The managed suite is installed under `~/.agents/skills/`. Start a new Codex session after installation. Core collaboration behavior remains in the shared Skills.

The Dashboard uses the shared CLI bridge and the private `dashboard policy` shared by every Agent platform. Before opening, run `dashboard ensure --json`: `managed` completes verified acquisition and recovery autonomously after one user-approved policy choice; `ask` requires one concise Agent question; `manual` returns the official browser download path. Do not repeat confirmations for resume, locks, checksums, or extraction. A normal open never updates a working Dashboard; use `dashboard ensure --update` only on an explicit user request. Use a stable session client ID; without a trusted shutdown hook, the local lease expires after about five minutes.
